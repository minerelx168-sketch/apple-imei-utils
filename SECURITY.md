# Security policy

This package is an offline utility. It does not authenticate devices, verify ownership, query carriers or Apple, or authorize payments. Treat a valid checksum as input validation only, never as access-control or proof of payment.

Please do not include real IMEIs, serial numbers, customer records, or credentials in public issues. Report security concerns privately to support@iunlockmobile.com, using synthetic examples and the affected package version. Avoid attaching production databases or logs.

The initial supported release line is 0.1.x. Security reports will be reviewed on a best-effort basis; no response-time guarantee is made.
